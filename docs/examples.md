# gaffy pictures of terms and rules

Generated by `npm run heuristics` ([scripts/examples.ts](../scripts/examples.ts)) with gaffy's own layout and text export; names made up. Rules: [heuristics.md](heuristics.md).

## Branches on a stem

A function hangs under parent caller.

```
foo.shoo()
├─> foo.magoo()
│   └─> foo.zoinks()
└─> foo.doo()
```

## Trunk: calls merging into one function

Calls into one function share trunk: Parent rule `dfs`: `doo()` hangs under `magoo()`; the call from `shoo()` joins the trunk.

```
foo.shoo()
├─> foo.magoo() ──┐
└─> foo.doo() <───┘
```

## Shared entry from the left (parent rule `joint`, default)



joint:

```
foo.shoo()
├─> foo.magoo() ────┐
└─> foo.zoinks() ───┤
    ┌───────────────┘
    └─> foo.doo()
```

dfs:

```
foo.shoo()
├─> foo.magoo() ────┐
└─> foo.zoinks()    │
    └─> foo.doo() <─┘
```
