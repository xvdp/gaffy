# gaffy pictures of terms and rules

Generated by `npm run heuristics` ([scripts/examples.ts](../scripts/examples.ts)) with gaffy's own layout and text export; names made up. Rules: [heuristics.md](heuristics.md).

## Branches on a stem

A function hangs under one caller, its parent: the parent's stem (vertical line under its first character) carries a branch `├─>`, `└─>` to each function hanging under it.

```
foo.shoo()
├─> foo.magoo()
│   └─> foo.zoinks()
└─> foo.doo()
```

## Trunk: calls merging into one function

Calls into one function share its trunk: one vertical line right of the labels it passes, entering the function at its end (`<─┘`). Parent rule `dfs`: `doo()` hangs under `magoo()`; the call from `shoo()` joins the trunk.

```
foo.shoo()
├─> foo.magoo() ──┐
└─> foo.doo() <───┘
```

## Shared entry from the left (parent rule `joint`, default)

A function with two or more callers in its group takes no parent unless a caller sits right above it; its callers' calls join one trunk that enters it from the left (`┌──┘`, `└─>`).

joint:

```
foo.shoo()
├─> foo.magoo() ────┐
└─> foo.zoinks() ───┤
    ┌───────────────┘
    └─> foo.doo()
```

dfs:

```
foo.shoo()
├─> foo.magoo() ────┐
└─> foo.zoinks()    │
    └─> foo.doo() <─┘
```

## Calls between groups: path search

Branches and trunks stay inside one group. Every other call gets its path by search on the character grid: the cheapest route around labels and frames, by bends, crossings and frame borders (h29).

```
╭┄ aloo.patata ┄╮     ╭┄ zoinks.jinkies ┄╮
┆  shoo() ────────┬────> doo()           ┆
┆  └─> magoo() ───┘   ╰┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄╯
╰┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄╯
```

## h13 Caller alignment

The top functions of a group take the row of their caller outside the group when free, so the call runs level.

on:

```
╭┄ aloo.patata ┄╮      ╭┄ zoinks.jinkies ┄╮
┆  shoo() ──────────────> scoobie()       ┆
┆  └─> magoo() ─────────> doo()           ┆
╰┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄╯      ╰┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄╯
```

off:

```
╭┄ aloo.patata ┄╮      ╭┄ zoinks.jinkies ┄╮
┆  shoo() ───────────┬┬─> doo()           ┆
┆  └─> magoo() ──────┘└─> scoobie()       ┆
╰┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄╯      ╰┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄╯
```

## h17 Group column, h18 Group row

A called group sits right of its calling group (h17), at its caller's row (h18); off, groups stack at the left edge, one below another.

on:

```

┆  shoo() ─────────────> doo() ─────────────────> magoo()  ┆

## h41 Callee group below its caller (one layer at a time)

Opening the callers of `magoo()`: the caller's group sits above, the group of `magoo()` below it, one indent right of the caller; off, side by side.

on:

```
╭┄ zoinks.jinkies ┄╮
┆  scoobie_doo()   ┆
╰┄┄│┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄╯
   │╭┄ aloo.patata ┄╮
   └─> magoo()      ┆
    ┆  └─> doo()    ┆
    ╰┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄╯
```

off:

```
╭┄ zoinks.jinkies ┄╮     ╭┄ aloo.patata ┄╮
┆  scoobie_doo() ─────────> magoo()      ┆
╰┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄╯     ┆  └─> doo()    ┆
                         ╰┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄╯
```

## h41 with two callers in the caller group

Only the last function of a group can drop its call through the frame; with two callers the group of `magoo()` sits right of their label ends, and both calls join one trunk.

```
╭┄ zoinks.jinkies ┄╮
┆  scoobie_doo() ─┐┆
┆  jinkies() ─────┤┆
╰┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄│╯
                  │ ╭┄ aloo.patata ┄╮
                  └──> magoo()      ┆
                    ┆  └─>>         ┆
                    ╰┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄╯
```

## h25 Search order

Calls are searched one at a time; each is an obstacle for the later ones. `row`: callers top to bottom; `longest`: the longest calls first.

row:

```
╭┄ aloo.patata ┄╮
┆  shoo()       ┆
┆  ├─> doo_be() ─────┐╭┄ zoinks.wibble ┄╮
┆  └─> magoo() ──────│─> doo()          ┆
╰┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄╯    │╰┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄╯
                     │ ╭┄ moo.goo ┄┄╮
                     ├──> zoinks()  ┆
                     └──> jinkies() ┆
                       ╰┄┄┄┄┄┄┄┄┄┄┄┄╯

## Markers

`>>` before a label: callers not shown; `└─>>` under it: calls not shown. A click opens them, or brings removed ones back.

```
>> foo.magoo()
└─> foo.doo()
    └─>>
```
